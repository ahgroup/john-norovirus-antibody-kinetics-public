## Repository structure and contents

-   `assets/` contains static figures or graphical elements not generated by code.
-   `data/` contains the datasets used in the analysis. These are the input data files read by the pipeline.
-   `logs/` contains log files produced by parallel workers during pipeline execution. It is useful for debugging and monitoring model fitting.
-   `products/` contains .qmd and compiled .docx manuscript and supplementary materials.
-   `R/` contains all R source files used in the analysis. These files define data processing, model fitting, posterior prediction, derivation of measures, and figure/table generation functions called by the pipeline.
-   `renv/` is automatically generated by the {renv} package. It stores the project-specific R library and ensures package version reproducibility. The renv.lock file records exact package versions used for the analysis.
-   `results/` contains figures and tables generated by the pipeline that appear in the manuscript and supplementary materials.
-   `targets.R` is the main pipeline definition file. It specifies the full reproducible workflow, including data processing, Bayesian model fitting, posterior prediction, sensitivity analyses, and figure/table generation. Running `targets::tar_make()` executes this pipeline in full.
-   `_targets/` is automatically generated by the {targets} package. It stores intermediate objects, metadata, and dependency information required for reproducible pipeline execution. This directory should not be modified manually.

## Reproducibility instructions

To reproduce our results, first clone or download this GitHub repository. Once downloaded, open the `.Rproj` file in Rstudio. We used the R package `targets` to implement the analysis pipeline which can be executed in full by running: `targets::tar_make()`. The pipeline automatically detects the number of cores on your device and runs in parallel, leaving two cores free. If you are in a limited computing environment, you can run sequentially by specifying `use_crew = FALSE`. Note that running all Bayesian models sequentially may be very slow. You can visualize the workflow using `targets::tar_visnetwork(TRUE)` and run only selected targets by passing a vector of target names to `tar_make()` optionally using tidyselect helpers. Due to OS and file system differences, some targets may appear outdated even if they are up-to-date. Note that not all model result files are included in the GitHub repository, as they exceed 10GB. To inspect or modify the Bayesian models, you will need to rerun the code.

One you have cloned our repository, follow these instructions to reproduce our results.

1.  Open the `john-norovirus-ab-kinetics-public.Rproj` file in Rstudio.
2.  Once renv initializes, run the command renv::restore() in the console to begin installing the required packages. If you have issues at this stage you can also install the dependencies manually, but if you do not use renv or you use different package versions than we did, our code might not work for you.
3.  If you want to run any steps that involve Bayesian models, you need to install cmdstan following the cmdstanr quick start guide at this location: <https://mc-stan.org/cmdstanr/articles/cmdstanr.html>. We used cmdstan version 2.38.0 for this project.
4.  Now you can run our pipeline by running `targets::tar_make()` in the console. If you would like to run of main text results only, run `targets::tar_make("reproduce_manuscript")` in the console. See the `_targets.R` file for further instructions and the full targets pipeline. If you are new to targets and want to learn more about how the pipeline works, we recommend reading the targets manual which can be found here: <https://books.ropensci.org/targets/>.

The full pipeline, including supplementary analyses, took us approximately 17 hours to run. To reproduce only the analyses and plots in the main text, run `targets::tar_make("reproduce_manuscript")` in the console. This took us approximately 6 hours to run.
